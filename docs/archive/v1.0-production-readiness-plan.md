## 1. Locked Architecture Decisions (Shipped in `v1.0.0`)

| Topic | Decision Implemented |
| :--- | :--- |
| **Database & Concurrency** | SQLite in **WAL mode** (`busy_timeout=5000`, `foreign_keys=ON`, `BEGIN IMMEDIATE` writes) replacing `schedule.json` — eliminates multi-worker Gunicorn race conditions with zero extra containers. |
| **Core Data Model** | Separate **`age_groups`**, **`rooms`**, and **`classes`** tables: every Class **requires** an Age Group (`NOT NULL`, `ON DELETE RESTRICT`), Rooms can exist with **0 classes**, and Classes are assigned to a Room (`NULLABLE`, `ON DELETE SET NULL`). |
| **Admin Accounts** | **Named multi-admin accounts** (`users` table with `super_admin` / `admin` roles, Werkzeug `scrypt` hashes, per-user/IP rate limiting, and full per-user audit log attribution). |
| **Upload Formats** | Standardize on **`.xlsx`** and **`.csv`** files only (server-side `openpyxl` + stdlib `csv`; removed client-side SheetJS `0.18.5`). |
| **Door Display Theme** | **Toggleable in Admin** (**Dark** slate default; **Light** warm off-white `#FAF8F4` option), synced live to all iPads. |
| **LBC Branding** | Self-hosted LBC logo in the main app header only (hidden on wall-mounted door kiosks `?kiosk=1`). |
| **Church Timezone** | `America/Chicago` (Lenexa, KS) with server clock offset synced to iPads. |

## 2. Completed Milestones (`v0.1-poc` -> `v1.0.0`)

1. **Milestone 1 (`prod/sqlite-backend`) — SQLite WAL Backend & Granular Concurrency-Safe API:** Modular `app/` package, 8-table schema, automatic idempotent `schedule.json` migration, ETag/304 `/api/state`, optimistic concurrency (`409`), overlap validation, debounced saves, and 8s Undo.
2. **Milestone 2 (`prod/security-hardening`) — Named Multi-Admin Auth & Security Hardening:** `users` table + CLI (`python -m app.cli`), fail-fast production secrets, `ProxyFix` + Cloudflare IP handling, SQLite-backed rate limiting, CSRF enforcement, hardened cookies, pure-DOM XSS elimination (zero `.innerHTML`), security headers, and per-user `audit_log`.
3. **Milestone 3 (`prod/excel-upload-pipeline`) — Hardened Server-Side Excel & CSV Pipeline:** Server-side `openpyxl` + `csv` parser with 5 MB cap, ZIP-bomb & magic-byte guards, two-step Preview -> Commit workflow, Preserve-Admin-Changes options, one-click Rollback snapshots, and formula-safe `.xlsx` export & template.
4. **Milestone 4 (`prod/age-groups-and-admin-ux`) — Dynamic Age Groups Manager & Redesigned Admin UX:** Age Groups CRUD + reorder + safe atomic reassignment on delete, curated WCAG AA (`>= 4.5:1`) palette + custom hex picker + live contrast badge & preview, 4-tab Admin Panel, Clear All Notices, Swap/Move Class, and Dark/Light theme toggle.
5. **Milestone 5 (`prod/kiosk-resilience-and-ops`) — Kiosk Resilience, Self-Hosted Assets & Ops Polish:** Self-hosted compiled Tailwind CSS & modular JS, strict `script-src 'self'` CSP, LBC logo header, PWA manifest, `localStorage` offline fallback, server-synced clock, progress bar & 30-min Up Next countdown, non-root privilege-dropping Docker entrypoint, and Docker `HEALTHCHECK`.
